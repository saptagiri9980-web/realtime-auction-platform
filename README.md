# 🔨 BidSpace - Real-Time Auction Platform

A secure, real-time auction platform where users can create auctions, bid live, and track highest bidders instantly.

> Built as a final year ISE project with a focus on clean code & manual testing.

### 📸 Screenshots
Add 3 images in /screenshots folder - Home, Live Bidding, Dashboard

## ✨ Key Features
- 🔴 Real-time bidding with WebSocket + STOMP + SockJS
- 🔐 JWT Authentication & Spring Security
- ⏳ Countdown timer with auto-expiry logic
- 👑 Live highest bidder tracking
- 📦 Seller dashboard to create/manage auctions
- 🗄️ MySQL database with optimized queries

## 🛠️ Tech Stack
- **Backend:** Java, Spring Boot, Spring Security, WebSocket
- **Frontend:** HTML, CSS, JavaScript / Thymeleaf
- **Database:** MySQL
- **Tools:** Git, Maven, Postman, JIRA
